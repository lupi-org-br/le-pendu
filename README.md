# le-pendu

Jogo de forca do Lupi!
Feito para explicar como se pode usar a API de teclado do aparelho.
Documentação da API em [lupi.api.br/docs](https://lupi.api.br/docs).

### A Branch lupinho é a versão adaptada para funcionar no Simulador lupinho.
Estável, mas ainda em Desenvolvimento...
